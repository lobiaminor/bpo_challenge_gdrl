# Solving task assignment problems at scale with DRL
This repository contains the code for the scientific paper "Automated decision-making for dynamic task assignment at scale".
The main scripts are train_graph.py, which serves as an entry point to the training routine, __main__.py, which serves as an entry point for the inference routine, and test_generalization.py, which serves as an entry point to for the inference on DTAPs different from the training one.
The scripts are heavily commented on for ease of usage and possible modifications. This codebase, that was developed for research motives, will be rearranged in the future to have a clear structure, and more guidance will be provided regarding its possible uses. The links to the data are provided in the original paper.
